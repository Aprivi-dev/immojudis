# Sale detail design references

The `accepted-*` screenshots are the canonical desktop and mobile references
for the three public states of a sale page:

- `discovery`: signed-in free access;
- `offer`: the Analysis access offer;
- `paid`: the full Analysis experience.

Exploration screenshots and local browser renders are intentionally excluded
from Git so that this directory stays limited to approved references.
